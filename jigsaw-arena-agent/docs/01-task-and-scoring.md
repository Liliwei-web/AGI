# 01 · 任务、环境与评分

## 题目

> 参考左侧的完整图片，将墙上位于最右侧的三个拼图块放置到 3×3 排布中的空缺位置。

3×3 拼图板缺了 3 格，同一面墙的货架行上停着 3 块待放拼图，要求把三块放回正确格位。左侧另有一张完整参考图，这是本题"预期"的视觉解法入口。

## 场景几何（每局固定）

| 元素 | 位置 |
| --- | --- |
| 板面 | 墙面 X ≈ 837 |
| 行（高度） | Y ∈ {155, 166, 177}，格距 11 |
| 列（沿墙水平） | Z ∈ {88, 99, 110}，格距 11 |
| 货架行（待放块停放处） | Y = 209，Z ∈ {82, 96, 110} |
| 参考图 | 板面左侧，(X≈837, Y≈105) |

每局真正变化的只有两件事：**哪三格被掏空**、**块上贴的是哪张图的碎片**。板面朝向（所有块的 yaw 众数）每局也会变。

坐标系提醒：墙面是 X≈837 的平面，**Y 是高度、Z 是沿墙的水平方向**。角色站在墙前只能沿 Z 方向移动，这一点是后面"最短走行排序"的基础。

## 可用动作（智能体侧接口）

| 类别 | 接口 | 说明 |
| --- | --- | --- |
| 感知 | `acquire_first_person_perception` | 返回第一人称图像 + 场景内物体列表（含 `object_id` / 位置 / 朝向 / AABB） |
| 移动 | `move_to_location` / `move_to_object` / `move_forward` | 角色移动 |
| 视角 | `look_at_location` / `look_at_object` / `turn_in_degree` | **实测对取景基本无效或不可复现**，见 `02-recon.md` |
| 抓取 | `move_and_take_object` / `move_and_take_puzzle_piece` | 走到目标并拿起，可指定手 |
| 放置 | `put_down_sth` | 放下手中物体，支持 `auto_rotate` 自动对齐朝向、`force_locate` |
| 查询 | `has_object_in_hand` | 查当前是否手持物体 |

真正解题只用到了四个：感知、移动（由抓取/放置内部自动完成）、`move_and_take_object`、`put_down_sth`。

## 评分

### 官方口径

拼图与整理房间任务采用「任务完成度 + 时间效率」综合评分；每题限时，超时后完成度照算、时间效率计 0。

### 实测口径

环境本身会给出两个数字：`jigsaw_score`（完成度分）与 `score`（总分）。用 64 次运行反推出的经验关系为：

```
总分 = 100 − 0.8 × (100 − jigsaw_score) − 0.0301 × 用时(秒)
（完成度判定为不通过时，总分直接记 0）
```

验证样本（括号内为实测）：

| jigsaw | 用时 | 公式值 | 实测 |
| --- | --- | --- | --- |
| 60 | 14.5s | 67.56 | 67.55 |
| 71 | 38.9s | 75.63 | 75.60 |
| 78 | 33.5s | 81.39 | 81.35 |
| 92 | 38.8s | 92.43 | 92.43 |
| 100 | 22.3s | 99.33 | 99.28 |
| 100 | 86.8s | 97.39 | 97.36 |

两条推论直接决定了后面的策略：

- **完成度是主导项**：每丢 1 分完成度扣 0.8 分总分，是时间项（0.03 分/秒）的两个数量级以上。
- **乱放有负收益**：一个错误排列曾拿到 46 分，低于空板的 49 分。所以"没把握就不放"是有数据支撑的策略。

### 满分上限

拼图全对时，总分上限由用时决定：22 秒约 99.3 分，38 秒约 98.8 分。也就是说，拼图任务的满分是 100，但**总分不可能拿到 100**。

## 信号从哪里来

| 模式 | 本地能否看到分数 | 说明 |
| --- | --- | --- |
| `train`（本地调试） | **能** | 写出明文 `eval_res.json`，含 `jigsaw_score` 与总分 |
| `test`（正式测试） | **不能** | 只写出加密的 `result_Preliminary*.bin`，评分在比赛平台侧完成 |

这个差异是理解整个项目难点的关键：**本地调试永远只出一道固定题**（多局重放中块 id、空槽、参考图完全一致，只有板面朝向在变），而正式模式每局随机出题且不给本地分数。这就造成了一个陷阱——在本地"满分"很容易，却完全无法反映随机题上的真实水平。第一代解法正是栽在这里（见 `04-lookup-table-era.md`）。
