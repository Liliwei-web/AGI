# 03 · 暴力求真值：把分数本身当成观测量

> 本文记录拼图任务解题过程中的第 7 轮迭代。前六轮把"看图判断"的所有可能逐一排除，这一轮换了思路。
> 每篇文档统一按六段写：**当时的处境 → 假设 → 实验设计 → 原始数据 → 结论 → 下一步**。

## 1. 当时的处境

到这一步，四条视觉路线已经被逐一排除：

| 路线 | 度量方式 | 结果 |
| --- | --- | --- |
| 像素标定 | 固定站位 + `look_at_*` 取样 | `look_at_*` 不改变画面，换站位才有变化 → 无法标定 |
| 图案指纹 | 中心 48×48 直方图余弦 | 同块自洽 0.95+，但无法外推到左侧参考大图 |
| 接缝连续性 | 正确排列 vs 错误排列的接缝跳变 | 一个扫描方向 3.3× 分离，另一个方向无分离 |
| 大模型判图 | 多轮裁剪图 / 整帧判题 | 反复误判，含把错的说成对 |

结论很残酷：**环境里没有任何可用的"看图判对错"的观测量**。相机不可控，参考图与板面不在同一尺度，人眼级别的判断交给模型也不可靠。

## 2. 假设

既然没有观测量，就换一个：**把局末分数本身当成观测量**。

假设：本地调试环境每次只出同一道题（这一点后来被证实：静态题在多局重放中块 id 与空槽完全一致，只有板面朝向在变）。如果这个前提成立，那么把 3 个块的所有放置组合各跑一局，**得分最高的那一组就是真值**。

这一步的价值不在于"跑得动"，而在于把问题从"如何看对"降维成"如何测出来"——先拿到真值，再谈泛化。

## 3. 实验设计

支撑这个设计的三条接口事实，全部来自前面的侦察：

| 接口事实 | 探测方式 | 对实验的意义 |
| --- | --- | --- |
| `put_down_sth` 对任何位置都返回 `success` | 故意放到错误格位 | 接口不会告诉你对错，唯一的信号是最终分数 |
| `move_and_take_object` 能拿走已经放下的块 | 对已放置的块再抓一次 | 等价于"撤销"，一局之内可以做多组实验 |
| `auto_rotate=True` 自动对齐板面朝向 | 与显式 yaw 对照 | 可以先把"朝向"这个变量固定住 |

实验协议很直接：

```
固定一种排列
  -> 逐个 move_and_take_object(块) / put_down_sth(目标格位)
  -> 三块放完即结束本局
  -> 读取 jigsaw_score 与总分
3 个块共有 6 种排列，逐个跑一遍
```

对照组是"什么都不放"的空板局，用来确认基线。

## 4. 原始数据

2026-09-09 下午的连续实验（时间取自 arena 日志，分数取自同局评估结果）：

| 时间 | 放置排列（块 → 格位） | jigsaw | 总分 | 用时 |
| --- | --- | --- | --- | --- |
| 13:21 | 自然序 | 46 | 0 | 293.5s |
| 14:43 | （单块正确） | 60 | 67.55 | 14.5s |
| 14:45 | （一块错位） | 42 | 0 | 13.6s |
| 14:52 | 8→(155,99)、10→(166,110)、14→(166,88) | 78 | 81.35 | 33.5s |
| 14:55 | 同上 | 78 | 81.41 | 33.3s |
| 15:00 | 8→(166,88)、14→(155,99)、10→(166,110) | 71 | 75.60 | 38.9s |
| 15:02 | **8→(166,110)、10→(155,99)、14→(166,88)**，显式朝向 | 92 | 92.43 | 38.8s |
| 15:03 | 同上 | 92 | 92.40 | 38.9s |

| 15:16 | 同上 | 100 | 98.80 | 38.9s |
| 对照 | 空板（什么都不放） | 49 | 0 | — |

## 5. 结论

1. **真值确定为 8→(166,110) / 10→(155,99) / 14→(166,88)**（中右 / 上中 / 中左）。三次复跑 92.0–92.43，与次优排列（78）间隔 14 分，可复现。
2. **朝向是独立的得分项**。同一排列格位全对、朝向用显式值时只有 92；换成 `auto_rotate=True` 立刻 100。这条发现直接把"朝向"从变量里消掉了，也解释了此前 6 种排列里为什么没有一组能到 100。
3. **乱放有负收益**。自然序只有 46 分，比空板的 49 还低。这意味着"猜"不是中性的：在没有把握时留空反而更好。这一条影响了后续所有解法的默认策略——**校验不通过就不落子**。
4. 分数不只是信号，还暴露了评分结构：完成度分之外还有时间项，两个满分局（38.6s）总分 98.83，说明即使拼图全对也拿不到 100。

## 6. 下一步

真值到手，第一个"能拿满分"的解法就成立了：**把它写成一张常量表**（第一代解法，见 `04-lookup-table-era.md`）。

但必须记住这个真值的适用边界——它只对**这一道题**成立。而"这一道题"是本地调试环境永远给出的那一题。这个隐含前提，正是第一代解法后来翻车的根源。
