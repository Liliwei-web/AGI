【拼图任务 · 视觉定位与放置规则】
场景：你的面前是一块拼图台/拼图板。最左侧是参考图（目标图案）；中间是拼图板，上面已有部分拼图块正确就位，其余是空缺槽位；附近放着待放置的拼图块。目标是把全部空缺槽位用对应拼图块按正确方向填满。

1. 看图与 ID 对齐：每轮先看第一视角组合图，并对照“可见物体列表”。所有拼图块/参考图都会以 object_id 出现在列表中，并带 place_location(X,Y,Z)、color、shape。物体动作只能使用当前帧列表里真实存在的 object_id，严禁编造或沿用旧 ID。
2. 定位空缺槽位：空槽本身没有 ID 和坐标，需要用同一行/列的相邻已就位拼图块的 place_location 推算中心点（槽位间距均匀；提示：所有拼图块的 X 坐标相同，只在 Y/Z 方向排布）。若看不全整体，先前往观察点 (X=750, Y=191) 正对拼图板环视一次，确认行列结构与空缺再行动；严禁凭空编造坐标。
3. 匹配与旋转：放置前先对照参考图和已就位块的图案、缺口朝向，判断“哪块放哪个空位、旋转多少度”。放置统一用 put_down_sth：target_location=槽位中心坐标，target_rotation 依次尝试 yaw=0/90/180/270；放不进（返回失败、块仍留在手上或被弹开）就换一个 yaw 再试，同一组合最多试 4 个角度；仍然失败说明块/槽不匹配，换别的空缺或待放块。
4. 反馈止损与节奏：每轮只输出一个动作。动作失败后不要再重复同参数，立即按上一条调整。避免原地反复转身；每次移动后只看一次，连续两帧无有效信息才再环视。整题约 400 秒，目标是尽快把 3 个空缺全部放对，放好的块不要再碰。
5. 结束条件：当所有空缺槽位都已放好、或确认没有可放的块后，输出 action 为 "finish_task" 的 JSON 结束任务；若题目是提问（数量/位置/颜色等），改用 submit_answer 作答。
