【拼图任务 v3 · 取放流水线规则】
任务目标：参考左侧完整图片，把墙面上“最右侧”的待放拼图块逐块放进 3x3 拼图板的空缺槽位。拼图板平面 X≈837。

硬性纪律：
1. 禁止连续输出与最近两次完全相同的 action+parameters（系统会拦截并报错），每轮都必须换参数：换目标 ID、换槽位坐标或换旋转角度。
2. object_id 与 place_location 一律以“可见物体列表”为准，只能用当前帧真实存在的 ID；图像仅用于确认外观与相对位置。已放好的块不要再碰。

判定待放块与空缺槽：
3. 3x3 网格的中心点只有少数几组 (Y,Z)（由已就位块的 place_location 归纳，例如 Y≈155/166/177、Z≈88/99/110，间距均匀）。place_location 不落在这些网格点上的拼图块，就是需要移动的“待放块”；网格内没有被占用的 (Y,Z) 点就是空缺槽心。
4. 每个动作只做一个目标，拿到一个待放块的 ID 后立即规划它的目标槽心（可对照参考图判断该块应放哪个空缺、旋转多少），不要犹豫。

取放流水线（关键）：
5. 手上无块时：不要手动走向待放块——move_and_take_object(块ID) 会自动走到该块并抓取。直接对下一个待放块 ID 调用它即可；若返回失败就换下一个待放块 ID。
6. 手上有块时：直接对推算出的目标槽心执行 put_down_sth：target_location=槽心坐标（X≈837），target_rotation 的 yaw 依次尝试 0/90/180/270（先试与参考图朝向一致的角）；成功后立刻回到第 5 条，取下一块。
7. 若某轮看不到任何待放块：先原地转身一次（只一次），再看新一帧的物体列表；列表里仍没有就用上一轮已知的待放块 ID 继续，不要反复往返同一坐标。
8. 结束条件：3 个空缺都已放好且手上无块时，输出 action 为 "finish_task" 结束；若题目是提问（数量/位置/颜色等），改用 submit_answer 作答。
