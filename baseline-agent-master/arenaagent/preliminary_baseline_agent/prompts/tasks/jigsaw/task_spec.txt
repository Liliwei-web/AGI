【拼图任务 v2 · 两段式执行规则】
任务目标：参考左侧完整图片，把墙面上“最右侧”的待放拼图块放进 3x3 拼图板的空缺槽位。拼图板所在平面 X≈837，空缺范围以系统给出的区域为准（一般 Y 152~180、Z 85~113）。

硬性纪律：
1. 禁止连续输出与最近两次完全相同的 action+parameters（系统会拦截并报错），每一轮都必须换参数：换目标 ID、换槽位坐标或换旋转角度。
2. object_id 与 place_location 一律以“可见物体列表”为准，物体动作只能用当前帧真实存在的 ID；图像仅用于确认外观与相对位置。
3. 已放好的拼图块不要再碰；拿取时避开已经就位的块。

两段式流程：
4. 拿块段（手上无拼图块时）：根据列表里各块的 place_location 判断哪些块不在 3x3 网格的行列对齐上（这些就是“最右侧待放块”），走到其中一块旁边执行 move_and_take_object(该块ID)。成功且手上有块后立即进入放块段；同一块两次拿取失败就换下一块，不要在同一个地方反复往返。
5. 放块段（手上有块时）：前往拼图板空缺区域（X≈837）。先由相邻已就位块的 place_location 推算空缺槽位中心坐标（网格间距均匀，中心点与相邻块对齐），然后用 put_down_sth：target_location=槽心坐标，target_rotation 的 yaw 依次尝试 0/90/180/270；同一槽 4 个角度都不行就换下一个槽。若某块所有槽都放不进，说明它不是空缺所需的块，把它放回待放区，换另一块重试。
6. 观察纪律：正对拼图板的观察点全题最多去一次；其余时间只在“待放块区域”与“拼图板”之间两点移动。看不到目标先转身一次确认，不要反复往返同一坐标。
7. 结束条件：3 个空缺都已放好且手上无块时，输出 action 为 "finish_task" 的 JSON 结束；若题目是提问（数量/位置/颜色等），改用 submit_answer 作答。
