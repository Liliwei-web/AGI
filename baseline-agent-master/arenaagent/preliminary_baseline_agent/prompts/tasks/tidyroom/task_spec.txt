【整理房间任务 · 视觉定位与摆放提示】
1. 每一轮先观察第一视角组合图：左半 RGB 画面用于判断物体外观、空间关系和遮挡；右半语义分割图上的数字标注与下方物体列表中的 object_id 一一对应。调用物体动作只能使用图中真实出现、列表里真实存在的 object_id，严禁编造或沿用旧 ID。
2. 看不到目标时不要对不存在的物体执行动作：先转身、移动或看向目标可能所在的方位，直到它在分割图中出现再抓取；若多次环视仍找不到，回到任务描述提到的区域附近继续搜索。
3. 拿取前先确认“拿哪个”：结合 RGB 外观与列表中的 color/shape/位置判断，避免拿错外观相近的物品。抓起后确认“当前手上有物品”再移动，一次只拿一个。
4. 放置规则：优先放到题目指定的目标家具或区域上方；参考物品自身大小与目标物体的包围盒选择落点。放到桌面、柜面、沙发等平面时要增加放置高度，避免悬空或陷入平面。放置后可回头观察图像确认位置正确。
5. 鞋子特别提醒：分辨“穿在人脚上的鞋”与“散乱在地上的鞋”，只整理题目要求整理的散乱物品，不要拿别人正在穿的鞋。
6. 结束条件：确认所有要求整理的物品都放到位后，再使用 finish_task 结束；若题目是提问（数量/位置/颜色等），改用 submit_answer 作答。
