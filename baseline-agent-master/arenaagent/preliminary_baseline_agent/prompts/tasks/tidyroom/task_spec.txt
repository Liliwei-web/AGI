【整理房间任务 v2 · 视觉定位与高效行动规则】
总目标：把客厅内杂乱摆放的抱枕、鞋子、垃圾、食物、杯子等整理到位。任务时间约 400 秒，只够约 15~25 次动作，每次动作都要一次成功，禁止空转。

1. 看图与 ID 对齐：每轮先看第一视角组合图——左半 RGB 判断外观与空间关系，右半分割图上的数字标注与下方“可见物体列表”的 object_id 一一对应。抓取/移动只能使用当前帧列表里真实出现的 ID，严禁编造或沿用旧 ID。
2. 拿什么（重要）：只拿“散乱摆放、属于整理对象”的物品。可拿的典型对象：掉在地上/桌外的抱枕、散落在地面的鞋、食品或杯子、垃圾。不可拿的对象：穿在人物脚上的鞋、别人手里或正在使用的物品、固定家具、墙上门窗、以及列表里没有实体外观（color/shape 为 Unknown 且像导航点/地面标记）的对象。拿取前把 RGB 里的外观和列表里的 color/shape/位置对上，认准了再执行。
3. 失败立即止损：动作返回 error（如 can not take this object）说明该 ID 不可拿或当前站姿不对，立刻换下一个目标。同一物体最多重试 1 次；同一个类别连续失败 2 次就整体放弃该类，转去处理视野中其它确定可拿的目标，绝不反复试错浪费回合。
4. 拿放循环：一次只拿一件。拿起后立即在当前视野里找放置面（茶几、桌子、柜面、沙发或归位区域），用该目标对象的 place_location 估算落点坐标（放到平面上时 Y 需加上物品半高，避免悬空或嵌入）。放成功后不再回头确认，立刻拿下一件。
5. 节奏控制：不要原地反复转身。每移动到一个新位置只看一次；连续两帧看不到整理对象就大步转身一次完成环视，然后直奔确定目标。宁可少环视，也要多完成“拿→放”。
6. 结束条件：当整个视野确认没有可整理的散乱物品、或已把所有能找到的对象放到位后，使用 finish_task 结束；若题目是提问（数量/位置/颜色等），改用 submit_answer 作答。
